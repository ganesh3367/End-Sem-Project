# Ganny's Furniture

Welcome to Ganny's Furniture - Your premier destination for elegant and comfortable furniture solutions in Pune, Maharashtra.

## About

Ganny's Furniture is a modern e-commerce platform that showcases a carefully curated collection of premium furniture. Our website offers an intuitive shopping experience with features designed to help you find the perfect pieces for your space.

## Features

### Shopping Experience
- Responsive product grid layout
- Advanced search functionality
- Category-based filtering (Living Room, Bedroom, Dining Room, Office, Kitchen, Storage, Lighting)
- Quick view product details
- Shopping cart functionality

### User Interface
- Modern and responsive design
- Intuitive navigation
- Mobile-friendly layout
- Beautiful product cards with hover effects
- Clean and professional styling

### User Features
- User authentication (Login/Signup)
- Product search and filtering
- Shopping cart management
- Contact form for inquiries
- Social media integration

## Technology Stack

- **Frontend**: React.js with Vite
- **Routing**: React Router DOM
- **Styling**: Modern CSS with CSS Variables
- **State Management**: React Hooks (useState)
- **Build Tool**: Vite
- **Version Control**: Git

## Getting Started

1. **Clone the Repository**
   ```bash
   git clone https://github.com/ganesh3367/End-Sem-Project.git
   cd End-Sem-Project
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```
